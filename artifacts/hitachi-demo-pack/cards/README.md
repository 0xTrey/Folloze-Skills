# Hitachi Vantara Folloze Demo Board Tiles

These assets follow the native Digital Sales Room `Example Folloze Boards` cover contract: 1672 x 941 landscape PNG, official company mark at the top, one short motion label, brand/Folloze gradient, and restrained geometric texture.

- `249545-hitachi-vantara-ai-ready-data-campaign-tile.png` - campaign example.
- `249544-hitachi-vantara-bmw-production-data-abm-tile.png` - one-to-one ABM example.
- `249546-hitachi-vantara-ai-data-foundation-event-tile.png` - event example.

The reusable deterministic renderer is in `source/board-cover-template.html`. Its background source is `source/hitachi-dsr-blue-background.png`; the official Hitachi Vantara logo is loaded from the first-party website. The output was verified at the exact DSR dimensions with no crop or overflow.
