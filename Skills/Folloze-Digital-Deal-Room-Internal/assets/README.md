## Demo Example Tiles

New Folloze MCP demo examples use a different, branded cover pattern:

- 1672 x 941 landscape PNG
- company logo at the top
- short motion or use-case label centered below
- account-appropriate gradient or brand color
- subtle geometric texture consistent with the template examples

Keep editable source files and final PNGs in the account demo's git-backed repo.
Use this skill directory only for reusable stock artwork, not account-specific
tile output.
