# Deal Room Asset Usage

Use the bundled reusable stock covers only for their approved asset types. Each is a `1254 x 1254` RGB PNG with a pale white/blue background and blue-to-purple illustration.

| File | Use only for | SHA-256 |
| --- | --- | --- |
| `assets/demo-call-recording-cover.png` | Processed buyer-facing demo call recordings | `83caaa153a9a6e5ade20e732aae93ab50fe914f6c23ce2355b1bf49d48177232` |
| `assets/presentation-deck-cover.png` | Presentation decks when the first slide is not a better preview | `d0ff5a11ff10294cfc9090710591400a532b1a14d40f74cc783d9b98174fea59` |
| `assets/order-form-cover.png` | Folloze order forms | `b01449e8e1d449ae361f3d4ba8484d78f9c8b8a6f0a5faff2c7821ba9a18e822` |

Do not reuse a stock cover for another asset type, custom demo example, guide, or walkthrough. The Folloze card title supplies asset-specific text; do not add a company logo or title directly to these stock images.

For new Folloze MCP demo examples, use a separate branded cover pattern:

- `1672 x 941` landscape PNG
- company logo at the top
- short motion or use-case label centered below
- account-appropriate gradient or brand color
- subtle geometric texture consistent with the template examples

Keep editable sources and final PNGs in the account demo's git-backed repo. Keep only reusable stock artwork in this skill.
