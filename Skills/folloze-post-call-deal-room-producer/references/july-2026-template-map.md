## Section Intent

### Header

- Replace the account placeholder and subtext.
- Preserve the existing navigation and CTA unless the user asks for changes.
- Use the target account's approved logo with enough contrast on the header background.

### Start With The Essentials

Prioritize the actual call follow-up package:

1. shared or promised sales deck
2. Folloze overview or analytics resource relevant to the buyer
3. the strongest matching case study or proof asset

Do not retain a prior account's deck title or link.

### Account-Specific Value Section

Rewrite all four cards from buyer-safe call priorities. Keep the existing native layout and concise card rhythm.

### Resources From Our Calls

Use this section for:

- the uploaded native demo recording
- approved demo-example pages shown or promised on the call
- other call-specific resources the buyer asked to revisit

Replace the `Folloze Demo Call Recording` placeholder with the uploaded asset. Do not embed Kaia.

### Integration Guides

Keep only the integrations that matter to the buyer's current stack or questions. Replace the account-specific heading.

### Case Studies

Select proof that matches the buyer's industry, motion, team structure, or goal. Replace the account-specific heading and remove irrelevant cards when the native section supports it.

## Visual QA

- Compare desktop and narrow layouts.
- Confirm both logos are crisp and legible against the same background.
- Replace a light customer logo on a light background with an approved dark or full-color variant; do not apply arbitrary CSS filters when an official variant exists.
- Check that dashboards, screenshots, thumbnails, and cards are level, centered, and not clipped.
- Confirm text that appears once in the visual layout is not mistaken for a duplicate merely because the designer DOM contains responsive or carousel variants.
