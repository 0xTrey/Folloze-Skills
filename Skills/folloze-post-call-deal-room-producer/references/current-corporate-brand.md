# Current Folloze Corporate Brand Direction

Source: `https://www.folloze.com/`

Observed: July 23, 2026.

Use the current public website as the visual source of truth for Board `248319` and rooms copied from it.

## Core Tokens

- deepest navy: `#071428`
- primary navy: `#1C293F`
- supporting navy: `#2C3D59`
- electric violet: `#5B5BFF`
- darker violet: `#3B3BE0`
- muted blue-gray: `#6B7E9D`
- white: `#FFFFFF`
- pale blue surface: `#F4F8FC`
- near-black text: `#141414`

## Typography And Components

- Display direction: Instrument Sans or the closest available native Folloze heading face.
- Body direction: Inter or the closest available native Folloze body face.
- Use large, compact headings with clear hierarchy.
- Use roughly 24px card radii where native components support them.
- Prefer subtle borders and restrained shadows.
- Use rounded pill CTAs where the native theme supports them.
- Keep generous white space and alternate white/pale-blue surfaces with occasional deep-navy proof sections.

## Template Application

- Header: white background, current official Folloze logo, dark navy navigation.
- Customer-logo slot: hidden in the universal template; enabled only after official logo harvest and contrast selection.
- Hero: deep navy gradient with restrained violet light, white copy, violet account-name accent.
- Hero visual: current Folloze product/campaign imagery rather than the legacy Magna image.
- Essentials: pale-blue supporting surface.
- Account priorities: white or pale-blue surface with simplified official line icons.
- Resources and integrations: white surfaces with clean native cards.
- Case studies: pale-blue surface or deep-navy proof treatment when supported by the native component.
