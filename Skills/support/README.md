# Support skills

CS and support troubleshooting skills for live Folloze boards.

These are internal operator workflows. They are not customer board builders. Keep credentials, cookies, tokens, customer data, and machine-specific paths out of this folder.

Current skills:

- `folloze-demandbase-personalization-qa`: discovery-first QA for personalization rules that depend on the Demandbase data-service integration. Folloze MCP plus browser DevTools evaluate. Do not treat first-party URL params as Demandbase proof.
