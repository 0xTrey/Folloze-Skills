# ABM Playbook for the AI Era outcomes

- The canonical Folloze-Skills repo holds the package at `Skills/abm-playbook-for-the-ai-era`.
- Folloze deal owners and demo builders currently adapt previous boards or assemble a new playbook from scratch.
- First successful use occurs when a deal owner accepts an evidence-backed playbook for a real opportunity. Repeat use means a second opportunity uses the same starter.
- Proposed owners are GTM leadership for business outcomes, Trey as first user and adoption lead, demo enablement for operations, and RevOps for measurement. Only the build has been authorized. Ongoing ownership remains unaccepted.
- To get started, the deal owner invokes the skill with an account name and source notes. The skill produces a local review, an embeddable fragment, and an internal evidence ledger.
